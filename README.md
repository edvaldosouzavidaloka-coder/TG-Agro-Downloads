TG Agro Diagnóstico PRO 🚜
Repositório público oficial para distribuir as versões do aplicativo TG Agro Diagnóstico PRO para Android.
Sobre o aplicativo
O TG Agro Diagnóstico PRO é uma ferramenta de consulta de códigos e referências técnicas de máquinas agrícolas. Inclui uma biblioteca para consulta offline, pesquisa na internet quando um código não é encontrado e uma opção de apoio voluntário ao projeto.
Baixar o aplicativo
As versões do APK serão disponibilizadas na seção Releases deste repositório:

Ver versões e downloads

Quando a versão 1.6.0 estiver publicada, abra a versão correspondente em Releases e baixe o arquivo .apk anexado.
Como atualizar
1. Baixe o APK da versão mais recente em Releases.
2. Abra o arquivo no celular Android e confirme a instalação.
3. Para atualizar sem desinstalar o aplicativo, o APK deve usar o mesmo identificador e a mesma assinatura da versão já instalada.
Atenção: instale apenas APKs publicados neste repositório oficial. O Android pode solicitar permissão para instalar aplicativos dessa origem.
Apoie o projeto
O aplicativo oferece uma opção de doação voluntária para ajudar a manter o serviço disponível. As consultas não dependem de doação.
Aviso
As informações disponibilizadas servem como apoio ao diagnóstico e não substituem a consulta aos manuais oficiais nem a avaliação de um profissional qualificado.
